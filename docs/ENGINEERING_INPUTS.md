# Инженерные входные данные

Этот файл заполняет инженер. Программа берёт отсюда значения по умолчанию для моделей
энергосистемы (T08), связи (T09) и мачты (T10).

Как заполнять:
- Впиши значение в столбец «Значение» и укажи в столбце «Источник или обоснование», откуда оно:
  ссылка на документ, паспорт изделия, расчёт или «инженерная оценка».
- Единицы менять не нужно. Если удобнее другие, напиши их явно рядом со значением.
- Пустая ячейка значит «не задано»: программа возьмёт временное значение и пометит его как
  допущение в docs/ASSUMPTIONS.md.
- Диапазон можно писать как «мин–макс (по умолчанию X)»: он станет пределами ползунка в приложении.
- Список значений пиши через точку с запятой: «0; 2; 5; 10; 20». Запятая в числе — всегда десятичная: «2,5» значит 2.5.
- Доли пиши числом от 0 до 1 без знака %: «0,3», а не «30 %». После числа можно дописать пояснение: «0.3 (на начало срока)».
- Метка «[предложено]» в столбце источника значит: значение предложено по открытым источникам и инженером ещё не подтверждено; приложение помечает его как неподтверждённое. Согласен — удали метку; не согласен — впиши своё значение.
